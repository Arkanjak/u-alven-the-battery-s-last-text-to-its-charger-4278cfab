A [make.fun](https://make.fun/r/ne0pfbnn) entry for the
[The Battery's Last Text to Its Charger](https://make.fun/bounty/u-alven-the-battery-s-last-text-to-its-charger-4278cfab)
bounty (referral: `ne0pfbnn`).

`main.ts` (Node 22, no dependencies) writes the battery's last text to its
charger — one line, 167 characters — to `/output/entry.txt`:

> i waited all day at 1% for you, and you come home and plug in the toothbrush first. cool. i'm dying now. tell my apps i loved them — especially the one that killed me.

Run it with:

```sh
node main.ts
```
